# user-client

BootMall C 端商城，技术栈为 React 19、TypeScript、Vite、Tailwind CSS 4、shadcn/ui 与 Lucide。

## 当前进度

本项目已完成初始化，但尚未开始业务开发。商品、购物车与下单依赖 M2 交易核心的后端接口；M2 目前仍待拆分，故不创建 Mock 业务、页面或接口调用。待对应后端卡片达到 DoD 后，再在实践计划中建立 C 端接入任务。

## 命令

```bash
npm install
npm run dev
npm run typecheck
npm run lint
npm run build
```

前端目录、请求、认证与验收规范见仓库根目录 [AGENTS.md](../AGENTS.md)。

## 📖 项目简介

本项目是一套**结构化、可持续更新的 Java 后端全栈学习路线**，以文档形式沉淀为一份「活的」知识库。

它不是从零开始的入门教程，而是为**已经具备服务器端开发经验**（如 NestJS / Node.js / Go）的工程师设计的能力迁移路线：

- **核心结论**：你已有的前端 / Node / Go 经验对 Java 后端学习的迁移价值远比想象中大——迁移的是心智模型（依赖注入、装饰器、模块化、异步、并发），重学的是 Java 语法与 Spring 生态。
- **明确避坑**：文档中专门标注了需要警惕的「直觉陷阱」，例如把 `Promise` 当 `CompletableFuture`、把事件循环当线程模型、把 TS 装饰器当运行时机制。

## 🗺️ 学习路线总览

|  阶段 | 主题 | 核心内容 |
|------|------|----------|
| **阶段 0** | 起点盘点与补课 | 能力迁移对照、工程环境清单、起步基础知识（注解/配置/依赖）、后端核心指标速览、迁移心智陷阱清单、专有名词速查 |
| **阶段 1** | Java 语言深化与 JVM 体系 | Java 8/17/21/25 特性、泛型反射注解、JVM 内存与 GC、JMM、并发编程、集合源码、IO/NIO、网络协议 |
| **阶段 2** | Spring 生态与 Web 开发核心 | Spring Framework、Spring Boot 实战、WebMVC 与 API 设计、WebFlux 选型、测试工程、Spring Security、NestJS 对比学习 |
| **阶段 3** | 数据持久化与中间件 | MySQL 内核与 SQL 优化、高可用与分库分表、ORM 数据访问、Redis 缓存体系、消息队列、Elasticsearch 与定时任务 |
| **阶段 4** | 微服务架构与分布式系统 | 微服务认知全景、Spring Cloud Alibaba、分布式核心理论、DDD 领域驱动设计、服务间通信与 RPC |
| **阶段 5** | 云原生与运维工程 | 容器化基础、Kubernetes、CI/CD 与平台工程、可观测性体系、Linux 与系统排查 |
| **阶段 6** | 架构设计与服务端思维 | 架构能力矩阵与请求链路、高性能 / 高可用架构、架构模式、安全架构、容量规划与压测、多租户设计 |
| **阶段 7** | 全栈融合与项目实战 | 全栈能力模型 + 三大实战项目（中后台 / 电商订单 / AI 应用平台） |
| **阶段 8** | 数据库专家 | 选型决策 + 七大数据库深挖 + 树与图算法基础 + 主从与副本设计 |

> 📈 排期总览：语言与 JVM（40 天）→ Spring 生态（35 天）→ 数据层（50 天）→ 微服务（50 天）→ 云原生（45 天）→ 架构与实战。详细甘特图见 [`docs/学习时间规划.md`](docs/学习时间规划.md)。

## 🚀 快速开始

### 📚 学习文档（无需构建，随开随读）

1. **GitHub 在线阅读** —— 直接浏览 `docs/` 目录，按阶段顺序学习；
2. **VS Code + Markdown 预览** —— 克隆到本地后使用 `Markdown Preview Enhanced` 等插件，完整渲染甘特图（Mermaid）等图表；
3. **Typora / Obsidian 等笔记软件** —— 作为个人知识库导入，支持双向链接与检索。

```bash
# 克隆仓库
git clone git@github.com:umlink/java-full-stack.git
cd java-full-stack

# 从阶段零开始，按顺序推进
# 打开 docs/00-阶段零-起点盘点与补课/01-能力迁移对照.md
```

### 🛠️ 实操工程（学完阶段零/二后动手跑）

仓库自带配套工程 [boot-app/](boot-app/README.md)（Spring Boot 4 多模块 + H2 + MyBatis-Plus），**只需本机装 JDK 25**（Maven 由仓库自带的 mvnw 提供，无需安装）：

```bash
cd boot-app
./mvnw -pl services/user-service -am install -DskipTests   # Windows 用 mvnw.cmd
./mvnw -pl services/user-service spring-boot:run            # 启动后访问 http://localhost:8080/api/users
```

### 推荐学习节奏

- **先读方法**：花 10 分钟读 [LEARNING.md](LEARNING.md)——AI 协助式学习的六种模式（追问式提问 / 苏格拉底 / 费曼 / 出题官 / Code Review / 卡点日志）与防 AI 依赖指南；
- **先盘点，再上路**：从「阶段 0 起点盘点」开始，明确自己「无需重学」与「必须重学」的部分；
- **边学边实现**：按 [实战产品蓝图](docs/10-实战产品蓝图.md)（BootMall 云市商城）把每个阶段学到的技术落进 [boot-app](boot-app/README.md)——每个技术点都挂在真实业务场景上；
- **一段一自检**：每完成一个阶段，对照该阶段末尾的「本节自检」清单做能力自检；
- **时间弹性**：主线约 9 个半月，时间不足可拉长周期，保持阶段间复盘即可。

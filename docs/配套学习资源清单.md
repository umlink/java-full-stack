# 配套学习资源清单

> 汇总大纲各阶段「推荐资源」。筛选原则：优先官方文档与经典书籍；每条给出用途与适用阶段。

## 通用（贯穿全程）

| 资源 | 用途 |
|-|-|
| 阿里巴巴 Java 开发手册 | 国内企业事实标准的代码规约，配合 IDE 插件实时检查（阶段 0 起全程遵守） |
| Martin Fowler 架构文集（网站免费） | 架构模式与演进思路的权威参考（配合阶段 4 / 6） |

## 阶段 1：Java 语言深化与 JVM

| 资源 | 用途 |
|-|-|
| 《Effective Java》第 3 版（Joshua Bloch，2018） | 经典条目式准则；基于 Java 9，读时结合新特性自行更新心智 |
| 《深入理解 Java 虚拟机》第 3 版（周志明） | JVM 与并发部分按需精读 |
| [Java 语言官方变更文档](https://docs.oracle.com/en/java/javase/25/language/java-language-changes.html) | 语言特性演进的第一手资料 |
| [JEP 索引](https://openjdk.org/jeps/0) | 跟踪各版本 JDK 增强提案 |
| [Project Loom](https://openjdk.org/projects/loom/) | 虚拟线程的设计文档 |
| [Project Leyden](https://openjdk.org/projects/leyden/) | AOT 启动优化路线图 |

## 阶段 2：Spring 生态与 Web 核心

| 资源 | 用途 |
|-|-|
| [Spring 官方文档](https://docs.spring.io/spring-framework/reference/) | 质量极高的第一手资料，首选 |
| 《Spring 实战》第 6 版（Craig Walls） | 覆盖 Spring 6 / Boot 3，概念在 4.x 依然适用 |
| [spring-boot 官方示例库](https://github.com/spring-projects/spring-boot/tree/main/spring-boot-project/spring-boot-starters) | starter 机制与自动装配的参考实现 |
| Spring Academy | 官方免费交互课程 |

## 阶段 3：数据持久化与中间件

| 资源 | 用途 |
|-|-|
| 《高性能 MySQL》第 4 版 | MySQL 与 SQL 优化主线书 |
| 《MySQL 技术内幕：InnoDB 存储引擎》第 2 版 | InnoDB 内核（索引 / MVCC / 锁） |
| 《Redis 设计与实现》（黄健宏） | Redis 数据结构与内部机制 |

| 《Kafka 权威指南》第 2 版 | 生产 / 消费 / 可靠性语义系统讲解 |
| [Elasticsearch 官方教程](https://www.elastic.co/guide/index.html) | 倒排索引、DSL 查询、聚合 |

## 阶段 4：微服务与分布式

| 资源 | 用途 |
|-|-|
| 《微服务架构设计模式》（Chris Richardson） | 微服务领域的百科全书，事件驱动 / Saga / CQRS 讲得最透 |
| 《实现领域驱动设计》（Vaughn Vernon） | DDD 战术 / 战略设计落地 |
| [Spring Cloud Alibaba 官方文档](https://sca.aliyun.com/) | Nacos / Sentinel / Seata 组件用法 |
| [Seata 官方文档](https://seata.apache.org/zh-cn/) | 分布式事务四种模式的原理与配置 |
| [Spring Modulith 官方文档](https://docs.spring.io/spring-modulith/reference/) | 模块化单体（微服务的务实替代路线） |

## 阶段 5：云原生与运维

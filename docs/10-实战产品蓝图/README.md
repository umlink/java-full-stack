# BootMall「云市商城」实战蓝图

> **一句话定位：一个渐进演进的电商平台。**
>
> 这份蓝图回答一个问题：**学到的东西往哪儿落**。它把学习路线中的知识点映射到真实产品，并把每次实践收束为可验证的小任务。概念细节以 `docs/` 各讲正文为准；本目录负责决定「现在做什么、为什么做、怎样验收」。

BootMall 合并了阶段七的三个实践方向：C 端商城、B 端管理后台与可选 AI 扩展。配套工程是 [boot-server](../../boot-server/README.md)，当前技术基线为 Spring Boot 4.0.0、Java 25、MyBatis-Plus 3.5.17 和 H2。

## 从这里开始

当前只推进 **M1 安全后台骨架**。已完成统一响应、创建用户请求 DTO 与创建参数校验；下一张实践卡片是「用户不存在业务异常」，会统一读取和更新时的资源缺失语义。完成并验证后，再依次处理 RBAC 表结构、注册、登录、授权和 OpenAPI。完整顺序见 [04-里程碑与当前计划](04-里程碑与当前计划.md)。

```mermaid
flowchart LR
    M0[M0 最小工程] --> M1[M1 安全后台骨架]
    M1 --> M2[M2 交易核心]
    M2 --> M25[M2.5 性能与异步]
    M25 --> M3[M3 服务化]
    M3 --> M4[M4 高并发证明]
```

## 使用规则

1. 先从 [实践计划](实践计划/README.md) 选一张当前已解锁的实践卡片。
2. 再到 [03-业务与技术映射](03-业务与技术映射.md) 确认技术选择和工程落点。
3. 涉及数据结构或服务边界时，先读 [02-领域模型与数据演进](02-领域模型与数据演进.md)。
4. 完成后必须留下测试和接口验证证据；引入重型技术前写一份 ADR。

蓝图内容一律维护在本目录；仓库内导航均指向本页。

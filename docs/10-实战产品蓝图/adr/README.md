# 架构决策记录（ADR）

返回 [蓝图总览](../README.md)。

ADR（Architecture Decision Record）用于记录一次会影响后续代码结构、数据模型或运行方式的技术决策。普通实现细节不需要 ADR；引入 Redis、MQ、微服务、分库分表、服务间一致性方案等需要。

## 模板

```markdown
# ADR-NNN：决策名称

日期：YYYY-MM-DD
状态：提议 / 已采纳 / 已废弃

## 决策

在 Mx 引入或移除什么能力。

## 触发信号与备选

观察到的业务或压测信号；列出至少一个更简单的备选方案，并说明为何不够。

## 影响与回退

新增的依赖、数据或运维成本；如果判断错误，如何回退以及预计成本。
```

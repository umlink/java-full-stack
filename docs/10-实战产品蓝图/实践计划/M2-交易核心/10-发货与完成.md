# M2-10：发货与完成

返回 [实践计划与进度](../README.md)。

## 目标

管理员能对 PAID 订单发货，用户确认收货后订单完成，状态机全链路闭环。

## 范围

- 新增 order:manage 权限码并关联 ADMIN（schema 增量）。
- GET /admin/orders B 端全量订单分页（order:manage）。
- POST /admin/orders/{id}/ship 发货（状态机条件更新 PAID→SHIPPED，order:manage）。
- POST /orders/{id}/confirm 确认收货（本人，SHIPPED→DONE）。

## 学习点

状态机完整矩阵（CREATED → PAID → SHIPPED → DONE / CANCELLED）、B 端与 C 端接口的权限分类。

## 验收

1. 全链路 CREATED→PAID→SHIPPED→DONE 顺序流转可走通。
2. 乱序迁移（如 CREATED 直接 SHIPPED、DONE 后 SHIPPED）返回 409/40900。
3. 普通用户访问 B 端接口 403/40300。
4. `./mvnw -pl services/user-service -am test` 通过。

## 不做

- 不做物流单号与收货地址（蓝图 ER 无此字段）。
- 不做 B 端前端页面（前端接入里程碑统一做）。

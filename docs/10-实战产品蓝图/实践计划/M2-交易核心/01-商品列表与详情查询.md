# M2-01：商品列表与详情查询

返回 [实践计划与进度](../README.md)。

## 目标

登录用户能分页浏览上架商品，并按 id 查看商品详情与 SKU 列表。

## 范围

- GET /products 分页（只返回上架商品，按 id 升序）。
- GET /products/{id} 详情聚合（商品信息 + SKU 列表 DTO）。
- 接口归类「仅认证」，无权限码。
- 响应 DTO 白名单，不暴露 deleted/version 等内部字段。

## 学习点

分页插件复用、多表聚合到 DTO、接口安全分类（公开 / 仅认证 / 权限保护）。

## 验收

1. 未登录访问返回 401/40100。
2. 登录后列表分页正确、详情含 SKU 与价格。
3. 下架商品不出现在列表，其详情返回 404/40400。
4. `./mvnw -pl services/user-service -am test` 通过。

## 不做

- 不做搜索与模糊查询。
- 不做缓存（M2.5）。
- 不做商品图片。

# M2-02：商品管理与改价

返回 [实践计划与进度](../README.md)。

## 目标

管理员能创建商品（含 SKU）并调整价格与上下架，并发改价冲突被拒绝。

## 范围

- 新增 product:manage 权限码并关联 ADMIN（schema 增量）。
- POST /products 创建商品与 SKU（请求 DTO 白名单，价格服务端校验非负）。
- PUT /skus/{id}/price 改价（乐观锁 @Version，version 不匹配返回 409/40900）。
- PUT /products/{id}/status 上下架。

## 学习点

权限码与 RBAC 关联、乐观锁冲突处理、写接口 DTO 白名单。

## 验收

1. 普通用户访问全部返回 403/40300，管理员成功。
2. 并发改价其一成功、另一返回 409/40900，不发生静默覆盖。
3. 上下架后 01 卡的 C 端可见性随之变化。
4. `./mvnw -pl services/user-service -am test` 通过。

## 不做

- 不做商品名称/描述编辑。
- 不做删除。
- 不做批量操作。
- 不做图片。

# M2-08：支付模拟

返回 [实践计划与进度](../README.md)。

## 目标

用户能对 CREATED 订单发起模拟支付，支付成功后订单转 PAID、预扣库存转实扣。

## 范围

- t_payment（id、order_id、pay_no 唯一索引、amount、status、create_time）。
- POST /orders/{id}/pay 模拟支付（渠道直接成功；生成 pay_no；订单状态机条件更新 CREATED→PAID，UPDATE ... WHERE status='CREATED'；库存实扣 total 与 locked 同步减 n；支付单与订单同一 @Transactional）。
- pay_no 唯一索引保证支付幂等。
- 已支付或已取消订单再次支付返回 409/40900 非法状态迁移。

## 学习点

状态机条件更新（幂等三板斧第三斧）、支付幂等键、库存实扣。

## 验收

1. 支付后订单为 PAID，库存 total 与 locked 同步扣减。
2. 重复支付同一订单返回 409/40900，不产生第二张支付单。
3. 对 CANCELLED 订单支付被拒。
4. `./mvnw -pl services/user-service -am test` 通过。

## 不做

- 不接真实支付渠道。
- 不做退款。
- 不做异步回调（模拟同步成功）。

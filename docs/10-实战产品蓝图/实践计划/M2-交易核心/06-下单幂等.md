# M2-06：下单幂等

返回 [实践计划与进度](../README.md)。

## 目标

同一用户携带同一幂等键的重复下单请求不重复创建订单。

## 范围

- 下单请求必填幂等键（idempotencyKey）。
- t_order 增加 user_id + idempotent_key 唯一索引。
- 重复请求命中唯一索引冲突后返回首次创建的订单（幂等重放语义，200 返回原单）。
- 并发同键请求只有一个成功创建。

## 学习点

幂等三板斧（token → 唯一索引 → 状态机条件更新）中的唯一索引方案、幂等键设计、并发幂等行为。

## 验收

1. 同键重复提交只产生一张订单，重放请求返回原单信息。
2. 不带幂等键的请求返回 400/40000。
3. 并发同键请求仅一单成功，其余拿到原单。
4. `./mvnw -pl services/user-service -am test` 通过。

## 不做

- 不做预发 token 接口方案（三板斧第一斧，按成本需要再引入）。
- 不做支付/取消场景的幂等（天然由状态机条件更新承担）。

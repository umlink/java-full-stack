# M2-04：库存表与管理

返回 [实践计划与进度](../README.md)。

## 目标

管理员能为 SKU 设置库存，预扣模型（total/locked）与条件更新语义就位。

## 范围

- t_stock（sku_id 主键、total_count、locked_count、update_time）。
- PUT /stocks/{skuId} 设置总量（product:manage 权限，条件更新校验调整后 total - locked 不小于 0，违反返回 409/40900）。
- GET /stocks/{skuId} 管理查询（返回 total、locked、available）。

## 学习点

预扣库存模型（total/locked/available）、数据库条件更新防超卖的基础语义。

## 验收

1. 管理员设置库存成功并可查询。
2. 将总量调到低于已锁定的请求被拒（409/40900），locked 不被破坏。
3. 普通用户 403/40300。
4. `./mvnw -pl services/user-service -am test` 通过。

## 不做

- 不做 Redis Lua 预扣（M2.5 出现压测信号后）。
- 不做库存分桶（M4）。
- 不做扣减接口（05 下单事务内完成）。

# M2.5-01：Redis 购物车

返回 [实践计划与进度](../README.md)。

## 目标

把购物车条目的高频读写迁入 Redis Hash，并保持用户隔离、数量边界和现价查询契约。

## 范围

- 以用户为边界设计购物车 Hash key 和字段。
- 加购、改数量、删除与列表走 Redis 适配器。
- 定义旧数据库购物车数据的迁移或清理策略、故障语义和指标。
- 通过 `catalog.api` 批量补齐商品现价，不把价格作为购物车事实。

## 学习点

Redis Hash、聚合数据所有权、原子字段更新、过期策略与数据迁移。

## 验收

1. 同一用户的购物车读写正确，不同用户互不可见。
2. 重复加购和并发改数量仍满足既有数量不变式。
3. Redis 故障行为、指标和恢复步骤有自动化与真实服务证据。
4. 受影响服务测试和全量回归通过。

## 验证命令

按开卡时锁定的 Redis 运行配置执行真实服务集成测试，再运行 `mvnw.cmd -pl services/user-service -am clean test` 与 `git diff --check`。

## 不做

- 不做库存预扣、订单异步化或前端页面。
- 不把商品价格复制为购物车权威数据。

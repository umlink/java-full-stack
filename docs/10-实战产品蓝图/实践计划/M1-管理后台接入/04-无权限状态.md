# M1-C-04：无权限状态

返回 [实践计划与进度](../README.md)。

## 目标

让已登录但没有后台权限的普通用户在请求被后端拒绝后看到明确、可恢复的无权限状态。

## 范围

- 请求客户端识别 `401/40100` 与 `403/40300` 的不同结果。
- `401` 清除会话并回到登录页；`403` 保留会话并展示无权限页面。
- 无权限页提供返回安全默认页或退出登录的操作。

## 学习点

HTTP 与业务码双层错误契约、前端状态机、后端授权边界。

## 验收

1. 使用普通 `USER` Token 请求 `/users` 时展示无权限状态，不被误判为登录失效。
2. 无效或过期 Token 返回 401 时清除会话并跳转登录页。
3. 页面不展示角色、权限码、堆栈或原始网络异常。
4. `npm run typecheck`、`npm run lint`、`npm run build` 通过。

## 不做

不在前端模拟权限，也不创建角色、权限管理页面。

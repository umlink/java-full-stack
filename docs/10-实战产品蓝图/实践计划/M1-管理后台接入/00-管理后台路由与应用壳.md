# M1-C-00：管理后台路由与应用壳

返回 [实践计划与进度](../README.md)。

## 目标

让 `admin-client` 从模板页变成可导航的管理后台应用壳，至少具备登录页和用户管理页的路由入口。

## 范围

- 引入 React Router，集中定义 `/login`、`/users` 和未匹配路径。
- 建立紧凑的后台布局与导航占位，不调用后端接口。
- 保留主题能力与现有 shadcn/ui、Lucide 使用方式。

## 学习点

SPA 路由、布局路由、页面组件与通用组件的职责划分。

## 验收

1. 浏览器可直接访问 `/login` 和 `/users`，页面结构稳定且路由切换无刷新。
2. 未匹配路径有明确跳转或 404 页面，不出现空白页。
3. `npm run typecheck`、`npm run lint`、`npm run build` 通过。

## 不做

不实现登录请求、Token、路由守卫或用户数据加载。

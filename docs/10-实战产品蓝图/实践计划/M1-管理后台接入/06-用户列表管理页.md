# M1-C-06：用户列表管理页

返回 [实践计划与进度](../README.md)。

## 目标

让管理员在管理后台查看真实用户列表，形成 M1 后端接口到 B 端页面的第一条完整链路。

## 范围

- 使用统一客户端调用 `GET /users` 并携带 Bearer Token。
- 用适合扫描的表格展示实际返回的允许字段。
- 实现加载、空数据、请求失败与无权限状态；保留刷新操作。

## 学习点

受保护 API 调用、表格信息密度、异步状态、后端 `Result<T>` 到页面模型映射。

## 验收

1. ADMIN 登录后可在 `/users` 看到真实列表，刷新页面仍可重新加载。
2. USER 登录后请求结果进入无权限页；无 Token 仍由路由守卫跳转登录。
3. 列表不显示密码哈希、Token 或其他敏感字段。
4. `npm run typecheck`、`npm run lint`、`npm run build` 通过，并完成浏览器手工验收。

## 不做

不做分页、搜索、编辑、删除、批量操作或角色配置；这些都拆成后续独立卡片。

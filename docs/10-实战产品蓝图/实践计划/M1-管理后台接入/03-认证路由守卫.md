# M1-C-03：认证路由守卫

状态：**待开始**  前置：M1-C-02 已完成

返回 [管理后台任务列表](README.md)。

## 目标

阻止未登录访客进入 `/users`，并让登录后的会话能安全地返回原目标页。

## 范围

- 为管理路由增加认证守卫，只判断 Token 是否存在。
- 未登录访问 `/users` 时跳转 `/login`，保留受控的返回地址。
- 已登录访问 `/login` 时跳转默认管理页；提供最小退出登录入口并清除会话。

## 学习点

路由守卫、重定向状态、会话恢复与退出清理。

## 验收

1. 无 Token 直接访问或刷新 `/users` 会跳转登录页。
2. 登录后返回原访问目标；退出后无法再进入受保护页。
3. 守卫不以本地角色决定访问结果，后端 403 留给下一张卡片处理。
4. `npm run typecheck`、`npm run lint`、`npm run build` 通过。

## 不做

不请求用户详情，不处理服务端 401，不实现权限菜单。

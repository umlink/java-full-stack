# M1-03：用户不存在业务异常

状态：**未解锁**  前置：M1-02 已完成

返回 [M1 任务列表](README.md)。

## 目标

把「用户不存在」从 Controller 中的条件表达式升级为可复用的业务异常。业务规则由 Service 表达，统一异常处理负责把它转换为 HTTP 404 和 `Result.fail(40400, ...)`。

## 范围

- 新增语义明确的业务异常类型。
- 在 Service 提供查询必存在用户的方法。
- 将 `GET /api/users/{id}` 改为使用该方法。
- 在全局异常处理器中映射为 40400。

## 学习点

Controller、Service、异常处理器的职责边界；HTTP 状态码与业务错误码的配合。

## 验收

1. 查询不存在 ID 返回 HTTP 404 和业务码 40400。
2. Controller 不再自己拼装「用户不存在」失败响应。
3. 已存在用户的查询行为不变，两个分支都有测试。

## 不做

不改删除和更新不存在时的语义；不建立复杂异常层级；不实现错误码枚举。

# M1-08：RBAC 管理接口授权

状态：**未解锁**  前置：M1-07 已完成

返回 [M1 任务列表](README.md)。

## 目标

将已认证用户的角色映射为权限，并用一个最小管理接口证明授权确实生效。

## 范围

- 从用户角色和角色权限读取当前主体的授权信息。
- 定义一个仅管理员可访问的管理接口，例如用户列表或用户状态管理。
- 配置角色或权限规则，使 admin 通过、普通用户拒绝。
- 区分 401（未认证）与 403（已认证但无权限）。

## 学习点

GrantedAuthority、角色和权限的命名、最小授权、401 与 403 的区别。

## 验收

1. 无 token 访问管理接口返回 401。
2. `USER` token 访问同一接口返回 403。
3. `ADMIN` token 访问成功，且测试覆盖三个分支。

## 不做

不做动态菜单、数据权限、组织树、前端路由守卫；不为了演示创建大量权限。

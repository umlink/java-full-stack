# M1-05：注册接口与密码哈希

状态：**待开始**  前置：M1-04 已完成

返回 [M1 任务列表](README.md)。

## 目标

新增用户注册行为。密码只保存 BCrypt 哈希，用户名或邮箱重复时明确拒绝；新用户默认拥有 `USER` 角色。

## 范围

- 为用户模型补充注册所需的用户名、密码哈希和状态字段。
- 新增注册请求 DTO 与注册接口。
- 使用 BCrypt 生成密码哈希。
- 用数据库唯一约束和业务检查共同防止重复注册。
- 注册成功后绑定默认 `USER` 角色。

## 学习点

密码哈希与加盐、唯一约束是最后防线、注册事务边界、默认权限分配。

## 验收

1. 数据库中不出现明文密码。
2. 相同用户名或邮箱再次注册失败，返回可理解错误。
3. 新用户只能获得 `USER`，不能由请求体指定 `ADMIN`。

## 不做

不做邮箱验证码、找回密码、第三方登录、密码复杂度策略和异步通知。

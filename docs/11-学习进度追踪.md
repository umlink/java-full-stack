## 里程碑复盘清单

- [ ] 阶段 0-3 完成 = 企业初级后端能力（Spring Boot CRUD + MySQL + Redis）
- [ ] 阶段 0-4 + 阶段 6 部分 = 企业中级后端（微服务 + 分布式排查 + 会写测试）
- [ ] 阶段 0-6 = 企业高级开发（架构设计 + 技术选型 + K8s + 可观测）
- [ ] 阶段 8 = 数据库专家加分项（多存储选型 + 主从/副本设计；可选/并行）
- [ ] 项目 1 跑通 = 全栈工程闭环（前后端分离 + 测试 + CI/CD）
- [ ] 项目 2 / 3 = 高并发方向 + 架构方向加分项

## 偏差处理规则

- 单个小点连续两次自检不达标 → 回读源文档对应章节，做最小验证再推进。
- 阶段进度落后 2 周 → 砍掉该阶段 P2 选学项，优先保 P0 / P1。
- 工作忙时间不足 → 只保阶段 1-3 硬基础；阶段 4-6 按工作方向调优先级（偏交付先保微服务，偏稳定性先保云原生 + 架构）。
